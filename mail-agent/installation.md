# Installation — teamver-mail-agent

## Requirements

- Python **3.11+**

## pip

```bash
pip install teamver-mail-agent
```

Pin:

```bash
pip install 'teamver-mail-agent==0.3.1'
```

Depends on `teamver-sdk-core`.

## Verify

```bash
python -c "import teamver_mail_agent as m; print(m.__version__)"
```
